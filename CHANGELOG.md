## [1.0.0] - 2026-08-20

### Added

Start of changelog for project.

Prior to tracking changes, the initial version of this software
provides the following IDR design functionality:

- Compute sequence features and human/yeast IDRome z-scores
- Design one feature mimic at a time given:
  - Input sequence
  - IDRome
  - RNG seed (to generate random initial sequence)
- Design one feature knockout at a time given:
  - Input sequence
  - IDRome
  - Features which will be set to IDRome minimum
